# Казахский Вайбометр 🐎🇰🇿

Мемный сайт: жмёшь кнопку, идёт отсчёт «үш · екі · бір», и степь выдаёт случайную оценку казахского вайба по 10-балльной шкале — «Сегодня казахский вайб на 7 коней из 10 юрт».

Все оценки 0–10 выпадают с равной вероятностью, изредка случается 11/10, а иногда вайбометр отвечает что-то совсем не по теме.

Чистый HTML/CSS/JS без сборки — готов к GitHub Pages. Звук синтезируется в браузере (WebAudio), без аудиофайлов.

## Графика

- 3D-эмодзи коня, беркута, барана, овцы, верблюда, кумыса, чая, чайника, яблока, тюльпана, лепёшки, мяса, короны и облаков — [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), лицензия MIT.
- Флаг, юрта, домбра, бешбармак, казы, баурсаки, шанырак и орнамент нарисованы вручную (SVG).
- Горы — процедурный рендер карты высот (`assets/img/mountains.webp`).
