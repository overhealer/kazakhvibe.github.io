# Казахский Вайбометр 🐎🇰🇿

Мемный сайт: жмёшь кнопку, идёт отсчёт «үш · екі · бір», и степь выдаёт случайную оценку казахского вайба по 10-балльной шкале — «Сегодня казахский вайб на 7 коней из 10 юрт».

Работает как Бин Бон из PEAK: все оценки 0–10 выпадают с равной вероятностью, изредка случается 11/10, а иногда вайбометр отвечает что-то совсем не по теме.

Чистый HTML/CSS/JS без сборки — готов к GitHub Pages. Звук синтезируется в браузере (WebAudio), без аудиофайлов.

Эмодзи флага, коня, беркута, барашка, чая, верблюда и молока — [Twemoji](https://github.com/jdecked/twemoji), CC-BY 4.0. Юрта, домбра, бешбармак, казы, баурсаки, шанырак и орнамент нарисованы вручную.
